## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline label padding |
| sm | 8px | Compact element spacing (e.g. category label to h1 gap) |
| md | 16px | Default element spacing, horizontal page padding (mobile) |
| lg | 24px | Section padding, FAQ item gap |
| xl | 32px | Layout gaps between major page sections |
| 2xl | 48px | Major section breaks (pt-12 on border-top section = 48px) |
| 3xl | 64px | Page vertical padding (py-16 = 64px on article root) |

Exceptions:
- Nav touch target: min-h-[44px] on all interactive elements (mobile menu button, close button, CTA link) — inherited from Phase 1 pattern
- Responsive iframe aspect ratio: `aspect-video` (16:9) with no fixed height — width drives layout
- Max content width: max-w-3xl (matches About and all editorial pages)

Source: `app/about/page.tsx`, `components/mobile-menu.tsx` (verified in codebase)

## Typography

| Role | Size | Weight | Line Height | Font | Color |
|------|------|--------|-------------|------|-------|
| Category label | 10px | 900 (black) | 1.2 | Inter | #cc2200, uppercase, tracking-widest |
| Body (regular and muted) | 16px | 400 (regular) | relaxed (1.625) | Inter | #f2f2ee (regular) / #888880 (muted) |
| Lead / intro paragraph | 18px (text-lg) | 400 (regular) | relaxed (1.625) | Inter | #f2f2ee |
| h2 (section headings, FAQ triggers, step titles) | 30px (text-3xl) | 900 (black) | 1.2 | Barlow Condensed | #f2f2ee |
| h1 (page title) | 48px (text-5xl) | 900 (black) | 1 (leading-none) | Barlow Condensed | #f2f2ee |

Notes:
- Exactly two declared weights: 400 (body and lead) and 900 (all headings and category label).
- No italic, no medium weight, no semibold. This is a brand constraint, not a default.
- Lead/intro paragraph is 18px — standard practice for editorial pages. Creates visual hierarchy between the intro and the step body copy without adding a heading level.
- Muted body copy (secondary text, footnotes, activation hints) uses 16px/400; color #888880 provides the visual distinction from regular body.
- h3 is folded into h2 (30px/900/Barlow Condensed). Step titles and FAQ triggers use the h2 style. At this content scale a two-level heading hierarchy (h1 + h2) is sufficient.
- Category label weight is 900 (font-black). The 10px size, uppercase, tracking-widest, and #cc2200 color together distinguish it from headings without requiring a separate weight.
- Step numbers in the process section use the same category label style (10px, 900, uppercase, #cc2200).

Source: `app/globals.css` @layer base, `app/about/page.tsx` (verified)

1. Category eyebrow labels above h1 (e.g. "The journey" / "Import guide")

6. Ring/focus indicator on interactive elements

Accent is NOT applied to: body text, section headings, FAQ triggers, accordion chevrons, the iframe wrapper, or muted footnotes.

### BuildVideo component

Interaction: purely conditional — no user interaction, no state.

```
props: { src?: string }

if src is undefined or empty string → return null (zero DOM footprint)
if src is a non-empty string →
  <div class="relative aspect-video w-full overflow-hidden rounded-sm">
    <iframe
      src={src}
      title="Build process video"
      allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture"
      allowFullScreen
      loading="lazy"
      className="absolute inset-0 w-full h-full"
    />
  </div>
```

Placement on About page: immediately before the CTA section. Gated by a `videoUrl` constant (defaults to `undefined`).

### FAQ Accordion

- Accordion type: single expand (only one item open at a time), or allow multiple (both acceptable — defer to executor preference, default to single)
- Trigger style: matches h2 visual weight (text-3xl font-black Barlow Condensed) but rendered as `<button>` by the Base UI primitive
- Chevron indicator: included in shadcn base-nova accordion by default; color inherits from foreground (#f2f2ee), rotates on open
- Border between items: uses `--border` (rgba(242,242,238,0.12))
- No background fill on accordion items — transparent over the page background (#0a0a0a)
- Content text: 16px body, #f2f2ee, leading-relaxed

### Nav link addition

Desktop nav: text-sm uppercase tracking-widest, #f2f2ee on rest, #cc2200 on hover. No truncation. "How it gets to you" is five words and fits in flex gap-8 layout at standard viewport widths.

Mobile nav: text-5xl font-black Barlow Condensed, #f2f2ee on rest, #cc2200 on hover. "How it gets to you" is longer than any existing label. If it wraps at 375px (iPhone SE), the executor may use a shorter mobile-only alias ("Import guide") while keeping the full label in the desktop nav — this is within Claude's discretion (D-11 locks the desktop label, not the mobile alias).

## Copywriting Contract

| Element | Copy |
|---------|------|
| Page category label | Import guide |
| Page h1 | Getting your Lambretta to Australia |
| Page intro | [Placeholder: orientative framing of the Malaga-to-Sydney journey. 2-3 sentences. Tone: "we handle this, here is what happens" — not a DIY guide. No exact cost figures.] |
| Step eyebrow labels | Step 01 / Step 02 / Step 03 / Step 04 |
| Step h2 headings | Pre-1989 historic exemption / Import and customs / Blue Slip inspection / Historic registration |
| Step body (each) | [Placeholder: 3-5 sentences per step. Orientative, not technical. No duty percentages or dollar amounts.] |
| FAQ section heading | Common questions |
| FAQ items | [Placeholder: 3-5 entries. Topics: duty, timeline, registration process, what the buyer needs to do (answer: very little).] |
| CTA section h2 | Still have questions? |
| CTA section body | [One sentence: real conversation framing, matches About page tone.] |
| Primary CTA label | Get in touch |
| CTA footnote | We reply within 2 business days. |
| BuildVideo title attr | Build process video |

Tone rules (all copy in this phase):
- No em dashes. Use commas, periods, or rephrase.
- No exact cost figures or duty percentages (D-03).
- Orientative and reassuring, not bureaucratic or technical.
- First person plural ("we handle this") not second person imperative ("you must do X").

Empty state: not applicable — no data lists or dynamic content in this phase.
Error state: not applicable — no forms or server actions in this phase.
Destructive confirmation: not applicable — no destructive actions in this phase.
