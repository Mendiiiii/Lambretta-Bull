## Spacing Scale

Declared values (multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline label padding |
| sm | 8px | Button icon-to-label gap, tight element spacing |
| md | 16px | Default padding inside cards, form fields, nav items |
| lg | 24px | Card-to-card gap, section internal padding |
| xl | 32px | Section-to-section vertical gap |
| 2xl | 48px | Major section breaks, above/below page hero |
| 3xl | 64px | Top-of-page hero padding, page footer separation |

Exceptions:
- Touch targets (mobile CTAs): minimum 44px height — use `min-h-[44px]` on all interactive elements
- Checkerboard stripe height: 8px (visual accent band, not a spacing token)
- Gallery thumbnail grid gap: 8px (`sm`)

## Typography

All headings use **Barlow Condensed**. Body and labels use **Inter**.

| Role | Size | Weight | Line Height | Font |
|------|------|--------|-------------|------|
| Display | 56px (text-5xl) | Black 900 | 1.05 | Barlow Condensed |
| Heading | 32px (text-3xl) | Black 900 | 1.15 | Barlow Condensed |
| Subheading | 20px (text-xl) | Black 900 | 1.3 | Barlow Condensed |
| Body / Label | 16px (text-base) | Regular 400 | 1.6 | Inter |

**Label differentiation:** When labels need visual distinction from body text, achieve it via `uppercase` + `tracking-widest`, not a separate weight.

**Letter spacing:**
- Display, Heading, and Subheading: `tracking-tight` (-0.025em) — condensed font, tight tracking reads as poster-print
- Body / Label: default tracking (0), or `uppercase tracking-widest` for label emphasis

**Global heading overrides in globals.css:**
```css
h1 { @apply text-5xl font-black tracking-tight leading-none; font-family: var(--font-barlow-condensed); }
h2 { @apply text-3xl font-black tracking-tight; font-family: var(--font-barlow-condensed); }
h3 { @apply text-xl font-black; font-family: var(--font-barlow-condensed); }
```

## Color

The Lambre-Bull palette is high-contrast black-and-white with a single Union Jack red accent. This is the 60s Mod / 2 Tone ska visual language: Jamaica Studio One label, Specials sleeve art, Fred Perry laurel on black, The Who roundel.

| Role | Hex / Token | Usage |
|------|-------------|-------|
| Dominant (60%) | `#0a0a0a` — `--color-brand-black` | Page background, primary surfaces |
| Secondary (30%) | `#f2f2ee` — `--color-brand-white` | Card surfaces, spec sheet backgrounds, form fields, text on dark |
| Accent (10%) | `#cc2200` — `--color-brand-red` | See reserved list below |
| Checker dark | `#1a1a1a` — `--color-brand-checker` | Checkerboard pattern dark squares |
| Destructive | `oklch(0.65 0.22 27)` | Form validation errors only |

**Accent (#cc2200) reserved exclusively for:**
1. Primary CTA buttons ("Inquire About This Bike", "Send Message")
2. Price anchor text ("from AU$XX,XXX") on bike listing cards
3. Active nav item indicator (left border or underline)
4. Checkerboard stripe separators (alternating red/white variant — used once per page max, at section breaks)
5. Focus ring (`--ring`) on interactive elements

**Accent is NOT used for:** body text, card borders, spec sheet values, headings, icon fills, secondary buttons, hover states on non-CTA elements.

**shadcn token mapping (replace :root block in globals.css):**
```css
:root {
  --background: #0a0a0a;
  --foreground: #f2f2ee;
  --card: #1a1a1a;
  --card-foreground: #f2f2ee;
  --popover: #1a1a1a;
  --popover-foreground: #f2f2ee;
  --primary: #cc2200;
  --primary-foreground: #f2f2ee;
  --secondary: #2a2a2a;
  --secondary-foreground: #f2f2ee;
  --muted: #2a2a2a;
  --muted-foreground: #888880;
  --accent: #cc2200;
  --accent-foreground: #f2f2ee;
  --destructive: oklch(0.65 0.22 27);
  --border: rgba(242, 242, 238, 0.12);
  --input: rgba(242, 242, 238, 0.10);
  --ring: #cc2200;
  --radius: 0.125rem;
}
```

**Note on radius:** `0.125rem` (2px). The 60s Mod aesthetic is geometric and angular — sharp corners. No rounded cards. Buttons get 2px radius maximum.

**No dark mode:** Lambre-Bull runs dark-only. The `.dark` class block should be removed. The site is always on a black ground.

## Checkerboard Pattern

The 2 Tone / Mod checkerboard is a structural brand element, not a decoration. Implementation rules:

- Pattern: 8px x 8px squares alternating `#f2f2ee` and `#1a1a1a`
- CSS: `background-image: repeating-conic-gradient(#1a1a1a 0% 25%, #f2f2ee 0% 50%) 0 0 / 16px 16px`
- Usage locations:
  1. Horizontal band above the page footer (8px height)
  2. Horizontal band below the site header / nav (8px height)
  3. Optional: bike listing card top-border accent (4px height stripe, not full checker band)
- Do NOT use as full-page backgrounds, card fills, or text backgrounds

## Layout Patterns

**No persistent sidebar.** Lambre-Bull is a public showcase, not a dashboard. The current sidebar layout from job-search-autopilot must be removed from the root layout for this site.

**Navigation:** Top nav, full-width, black background. Logo left, nav links right. Nav links: "Bikes", "About", "Contact". No hamburger accordion — at mobile, collapse to logo + single "Menu" button opening a full-screen overlay.

**Page structure:**
```
<header> — sticky, black bg, 64px height
  <checkerboard-stripe> — 8px, below header
<main>
  <hero-section> — full-width, large display heading, bike hero image
  <content-sections> — max-w-6xl, mx-auto, px-[16px] md:px-[32px]
<footer>
  <checkerboard-stripe> — 8px, above footer
  <footer-content> — black bg, white text, minimal
```

**Bike listing page (`/bikes/[id]`):**
- Left: photo gallery (8-12 images), primary image large, thumbnails below in a 4-column grid
- Right: spec sheet + price anchor + inquiry CTA
- On mobile: gallery full-width stacked above spec sheet
- No lightbox in Phase 1 — gallery images are full-width click-to-next. Phase 2 can add lightbox.

**Gallery interaction:**
- Click thumbnail: swaps primary image (CSS class toggle, no JS library)
- Primary image: `aspect-[4/3]`, `object-cover`, `next/image` with `priority` on the first image
- Thumbnails: `aspect-square`, `object-cover`, 8px gap grid

**Contact form:**
- Centered, max-w-lg, on black background
- Fields: Name, Email, Subject (pre-loaded from bike CTA), Message
- Submit: full-width primary button
- No modal — standalone `/contact` page

## Copywriting Contract

| Element | Copy |
|---------|------|
| Primary CTA (per-bike) | "Inquire About This Bike" |
| Primary CTA (standalone contact) | "Send Message" |
| Nav CTA | "Get in Touch" |
| Price anchor label | "from AU$" (value follows inline, red, uppercase) |
| Spec sheet section heading | "Specifications" |
| Gallery section heading | omit heading — photos speak for themselves |
| About page CTA | "Ask About a Build" |
| Contact form: subject pre-fill (from bike CTA) | "Inquiry: [Bike Name/Year]" |
| Empty state: no bikes listed | "No bikes available right now. New builds are underway — get in touch to be first to know." |
| Form success state | "Message sent. We'll be in touch within 2 business days." |
| Form error state (generic) | "Something went wrong. Try again or email us directly at [address]." |
| Form error state (field validation) | Inline, below the field: "Please enter a valid email address." / "This field is required." |
| Destructive actions | None in Phase 1 — no delete/remove actions exist on the public-facing site |

**Tone rules:**
- No superlatives ("world-class", "unique", "stunning") — let the photography do that
- No passive voice on CTAs — always imperative: "Inquire", "Send", "Ask"
- Price anchor is always present — never "Contact for pricing" or "POA"
- Response time commitment appears on the contact form success state and below the form CTA

## Interaction States

All interactive elements must declare all four states:

**Primary Button (CTA):**
- Default: `bg-[#cc2200] text-[#f2f2ee]`, 2px radius, `px-6 py-3`, font Barlow Condensed Black 16px uppercase
- Hover: `bg-[#a81c00]` (10% darker red), transition 150ms ease
- Focus-visible: 2px red outline, 2px offset (uses `--ring`)
- Disabled: `opacity-40 cursor-not-allowed`

**Secondary / Ghost Button:**
- Default: transparent bg, `border border-[rgba(242,242,238,0.3)]`, white text
- Hover: `bg-[rgba(242,242,238,0.08)]`
- Focus-visible: same as primary
- Disabled: `opacity-40 cursor-not-allowed`

**Form Input:**
- Default: `bg-[rgba(242,242,238,0.06)] border border-[rgba(242,242,238,0.12)]`, white text, 2px radius
- Focus: `border-[#cc2200]`, `ring-1 ring-[#cc2200]`
- Error: `border-destructive`, red inline message below field
- Disabled: `opacity-40`

**Thumbnail (gallery):**
- Default: `opacity-70`
- Hover: `opacity-100`
- Active (selected): `opacity-100 ring-2 ring-[#cc2200]`

**Nav link:**
- Default: white text, no underline
- Hover: `text-[#cc2200]`, transition 100ms
- Active (current page): `text-[#cc2200] border-b-2 border-[#cc2200]`

## Accessibility

- All images: descriptive `alt` text required. Bike photos: "[Year] [Model] — [angle, e.g. left side profile]"
- Color contrast: white (`#f2f2ee`) on black (`#0a0a0a`) = 19.4:1. Exceeds WCAG AA.
- Red (`#cc2200`) on black (`#0a0a0a`) = 5.1:1. Passes WCAG AA for large text (18px+) and UI components.
- Red on white: do not use — contrast ratio is 4.0:1, insufficient for body text.
- Form labels: always visible (no placeholder-only labels)
- Skip link: preserve existing `.skip-link` implementation from globals.css
- Focus ring: `*:focus-visible` uses `--ring` (red) — already declared in globals.css, keep it
